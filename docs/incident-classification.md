# Классификация инцидентов в IT

Шпаргалка команды для дашборда МТС. У одного инцидента есть несколько независимых признаков. Например, он может одновременно быть критическим и находиться в очереди координаторов.

## Уровни для фильтра и графа

Переключатель над графом выбирает, что смотреть. Инциденты фильтруем по типу влияния из `serviceType`, а представление графа выбираем по уровню.

| Уровень | Что показываем на графе | Пример инцидента |
| --- | --- | --- |
| Клиентский | Шаги клиента: вход → корзина → оплата. На узлах видны доля успешных действий, задержка и число затронутых сессий, если оно измеряется | Клиенты не могут завершить оплату |
| Внутренние пользователи | Рабочие процессы сотрудников, например обработка заказа и возврата | Операторы не могут оформить возврат в CRM |
| Технический | Сервисы, API, очереди, БД и инфраструктура. На узлах видны метрики и зависимости | Растёт очередь фоновых задач |

Один инцидент может открываться в нескольких представлениях. Когда клиентский шаг «Оплата» подсвечен, переход «Показать зависимости» открывает связанные Checkout, Payment API и PostgreSQL. При этом выбранный инцидент остаётся тем же. Связь шагов с сервисами задаём в конфигурации стенда.

## Основные термины

| Термин | Что значит | Пример |
| --- | --- | --- |
| Событие | Изменение, которое зафиксировала система | Задержка оплаты выросла |
| Алерт | Сигнал о событии, которое требует внимания | Мониторинг сообщил о росте ошибок оплаты |
| Инцидент | Незапланированный сбой или ухудшение качества работы сервиса | Часть клиентов не может оплатить заказ |
| Проблема | Причина или возможная причина одного или нескольких инцидентов | Нехватка соединений с БД |
| Запрос на обслуживание | Обычная заявка пользователя на услугу | Выдать доступ новому сотруднику |

## Признаки инцидента

| Признак | На какой вопрос отвечает |
| --- | --- |
| Влияние · Impact | Кого и насколько затронул сбой? Например, один клиент или все оплаты по продукту |
| Тяжесть · Severity | Насколько серьёзны последствия по шкале команды? Например, `SEV1` при остановке критичного сценария, если так определена шкала |
| Срочность · Urgency | Как быстро нужно вмешаться? Например, прямо сейчас или до ближайшего расчётного периода |
| Приоритет · Priority | Что берём в работу первым? Обычно зависит от влияния и срочности |
| Статус · State | На каком этапе работа? Назначен, выполняется, решён, закрыт или исследуется |
| Назначение · Assignment | Какая команда и какой сотрудник ведут инцидент? |
| Дедлайн · Deadline | До какого момента нужно устранить сбой? SLA — соглашение об уровне сервиса, которое может задавать целевой срок |

[Пример шкалы тяжести SEV](https://www.atlassian.com/incident-management/kpis/severity-levels)

## Как это читается в данных МТС

- **Приоритет `priorityId`.** 4 — наивысший, 3 — высокий, 2 — средний, 1 — низкий. Нумерация своя у каждого проекта.
- **Тип сервиса `serviceType`.** Клиентский — затронуты клиенты. Пользовательский — затронуты пользователи внутренних систем. Технологический — влияние ограничено внутренним компонентом или процессом.
- **Статус `stateEnum`.** `Assigned` — назначен, `WorkInProgress` — в работе. Оба статуса активные. `Resolved` — сбой устранён, `Closed` — запись закрыта. `Research` — сбой уже устранён, разбираются причины. При реализации опираемся на `stateEnum`, поскольку значения числового `stateId` для завершения расходятся со справочником.

| Группа на дашборде | Правило проекта |
| --- | --- |
| Критические | Активный инцидент с `priorityId = 4` |
| Высокий приоритет | Активный инцидент с `priorityId = 3` |
| На координаторах | Активный инцидент или исследование, назначенное на «КЦ ИТ Координаторы Массовых Инцидентов» |
| Исследование ситуации | `stateEnum = Research`. Карточка здесь видна и при заполненной дате устранения |

**Пример.** Оплата заказов сломалась, приоритет 4, статус `Assigned`, назначение на координаторов. Карточка видна в «Критических» и «На координаторах». После восстановления оплаты дашборд показывает отметку о решении. Если запись перевели в `Research` и оставили на координаторах, она видна в «Исследовании ситуации» и «На координаторах».

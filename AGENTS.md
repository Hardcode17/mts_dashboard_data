# MTS Dashboard Data

Репозиторий документации, исследований и материалов проекта MTS Dashboard.

## Что здесь лежит

- `docs/` — аналитика, планы, разборы данных и вопросы.
- `Предоставленные материалы/` — исходные материалы от заказчика.
- `.obsidian/` — локальная конфигурация Obsidian, не трогать без необходимости.

## Правила

- Документы пишем на русском, код и имена файлов — на английском.
- Не удаляй и не переписывай исходные материалы без явной просьбы.
- Новые документы клади в `docs/`, если это не согласовано иначе.
- Ссылки на другие репозитории давай полными: `Hardcode17/mts_dashboard_*`.

## Jira

Работа с задачами ведётся по общей инструкции: [`docs/agents/jira.md`](docs/agents/jira.md).

- Проект: `KAN`, доска общая для frontend, backend и data.
- В этом репозитории используй метку `repo:data`.
- Перед созданием задачи ищи существующую, не плоди дубли.
- Не бери задачи с метками `repo:frontend` и `repo:backend`.
